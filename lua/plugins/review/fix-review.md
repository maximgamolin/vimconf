---
description: Исправить замечания локального ревью из .review/
---

В корне репозитория есть папка `.review/` с замечаниями ревью. Каждый файл
`.review/*.md` относится к одному файлу проекта и устроен так:

```markdown
---
file: src/app/main.py     # путь к файлу проекта (источник истины)
base: a1b2c3d             # левая ревизия сравнения
head: e4f5a6b             # ревизия, к которой привязаны номера строк
---

## L42                    # строка (или диапазон ## L57-L60) в head-версии
> цитата строки кода      # как строка выглядела на момент ревью
Текст замечания.
```

Твоя задача:

1. Прочитай все файлы `.review/*.md`.
2. Для каждого замечания найди место в коде. Якоря, в порядке надёжности:
   сначала ищи процитированные строки (`>`) в текущем файле; номер строки —
   подсказка, где искать (код мог сдвинуться после ревью); при спорных
   случаях сверься с `git show <head>:<file>`.
   **Если цитата в файле не находится и место неоднозначно — не угадывай,
   спроси меня.**
3. Исправь код по замечанию. Если замечание — вопрос, а не требование
   правки, ответь на него мне в чате и считай закрытым.
4. Когда все замечания по файлу закрыты — удали его файл замечаний из
   `.review/`. Когда закрыты все — папка `.review/` должна исчезнуть.
5. Прогони тесты/линтеры проекта, если они есть.
6. Сделай коммит с исправлениями и удалением `.review/` (историю замечаний
   сохраняет git — файлы были закоммичены до тебя).

Не переформатируй код вокруг и не делай правок сверх замечаний.
